LINEFM Radio - native libraries / Native Bibliotheken (Windows, Linux)

The desktop versions play audio through libmpv, which contains FFmpeg. These
libraries are licensed under the GNU Lesser General Public License (LGPL).
They ship as separate files (libmpv-2.dll on Windows, libmpv.so on Linux) and
can be replaced with a compatible build of your own. The full license texts
are in LGPL-3.0.txt and GPL-3.0.txt next to this file.

Die Desktop-Versionen spielen Audio ueber libmpv, das FFmpeg enthaelt. Diese
Bibliotheken stehen unter der GNU Lesser General Public License (LGPL). Sie
liegen als eigene Dateien bei (libmpv-2.dll unter Windows, libmpv.so unter
Linux) und lassen sich durch einen eigenen, kompatiblen Build ersetzen. Die
vollstaendigen Lizenztexte liegen als LGPL-3.0.txt und GPL-3.0.txt daneben.

Windows (libmpv-2.dll)
  Build: media-kit libmpv-win32-audio-build, release 2023-09-24
         mpv-dev-x86_64-20230924-git-652a1dd.7z
         https://github.com/media-kit/libmpv-win32-audio-build/releases/tag/2023-09-24
  Build scripts: https://github.com/media-kit/libmpv-win32-audio-build
  mpv:    v0.36.0-403-g652a1dd907, built with -Dgpl=false
          LGPL-2.1-or-later
          https://github.com/mpv-player/mpv/tree/652a1dd90711839acdccc08004056d25514ef2d8
  FFmpeg: built with --disable-gpl --disable-nonfree --enable-version3
          LGPL-3.0-or-later
          https://ffmpeg.org/download.html
  The DLL as a whole is therefore covered by LGPL-3.0-or-later.
  Also statically linked (non-GPL): zlib, libpng, libjpeg-turbo, libarchive,
  lcms2, OpenAL Soft (LGPL-2.0-or-later), mujs (ISC).

Linux (Flatpak)
  Built from source in the Flatpak manifest (packaging/flathub/de.linefm.app.yml):
  mpv 0.42.0 with -Dgpl=false (LGPL-2.1-or-later), https://github.com/mpv-player/mpv
  FFmpeg 8.0 without --enable-gpl (LGPL-2.1-or-later), https://ffmpeg.org
  libass (ISC), https://github.com/libass/libass
  libplacebo (LGPL-2.1-or-later), https://code.videolan.org/videolan/libplacebo

Linux (Snap)
  Built from source in packaging/snap/snapcraft.yaml with the same versions
  and options as the Flatpak: mpv 0.42.0 with -Dgpl=false (LGPL-2.1-or-later),
  FFmpeg 8.0 with --disable-gpl --enable-version3 (LGPL-3.0-or-later),
  libplacebo (LGPL-2.1-or-later); libass from Ubuntu (ISC).
