# config/

Einstellungen zum Bauen der App, je Thema eine Datei. Im Repository liegen nur Beispiele (`*.example.json`) und die Senderliste (`stations.json`). Zum Nutzen eine Beispieldatei kopieren, `.example` aus dem Namen entfernen und ausfüllen. Echte Dateien bleiben lokal (`.gitignore`); fehlt eine, ist die Funktion aus.

Anleitung: [docs/KONFIGURATION.md](../docs/KONFIGURATION.md), Senderliste: [docs/SENDER-VERWALTEN.md](../docs/SENDER-VERWALTEN.md). Prüfen: `dart run tool/check_config.dart`.
