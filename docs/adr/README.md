# Architekturentscheidungen (ADR)

Jede Datei hält eine Entscheidung fest, die die App oder ihren Betrieb prägt: Kontext, Entscheidung, Folgen, verworfene Alternativen. Die Entscheidungen stammen vom Inhaber und aus der Planung vom 18. und 19.11.2026. Eine Datei wird nicht umgeschrieben, wenn sich die Lage ändert. Stattdessen kommt eine neue Datei dazu, die alte bekommt den Status "ersetzt durch ADR NNNN".
