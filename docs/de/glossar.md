# Glossar

| Begriff | Bedeutung |
|---|---|
| ADR | Architekturentscheidung: eine Datei je Entscheidung, siehe [Übersicht](../adr/README.md) |
| ARB | Übersetzungsdatei von Flutter unter `lib/l10n/` |
| Attestierung | Von GitHub signierter Herkunftsnachweis für eine Release-Datei |
| axe-core | Automatische Prüfung auf Barrierefreiheit, läuft in der CI über die Web-Version |
| BFSG | Barrierefreiheitsstärkungsgesetz |
| cosign | Werkzeug zum Signieren und Prüfen von Dateien (Sigstore) |
| Deep Link | Link, der direkt einen Sender öffnet, etwa `linefm://play?station=<sender>` |
| Golden-Test | Bildvergleich einer Oberfläche gegen ein gespeichertes Referenzbild |
| laut.fm | Plattform, über die die Sender ausgespielt werden und von der die App Daten holt |
| Provider | Baustein der Zustandsverwaltung (Riverpod) |
| SBOM | Stückliste aller Bestandteile eines Releases |
| Scorecard | OpenSSF-Prüfung der Sicherheitspraxis eines Repositories |
| TDDDG | Telekommunikation-Digitale-Dienste-Datenschutz-Gesetz, regelt die Einwilligung beim Zugriff auf Endgeräte |
| Vorabversion | Release mit Zusatz `alpha`, `beta` oder `rc`, geht in keinen Store |
