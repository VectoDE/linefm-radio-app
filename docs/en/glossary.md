# Glossary

| Term | Meaning |
|---|---|
| ADR | Architecture decision record: one file per decision, see the [index](../adr/README.md) (German) |
| ARB | Flutter translation file under `lib/l10n/` |
| Attestation | Provenance proof for a release file, signed by GitHub |
| axe-core | Automatic accessibility check, runs in CI against the web version |
| BFSG | German Accessibility Strengthening Act (Barrierefreiheitsstärkungsgesetz) |
| cosign | Tool to sign and verify files (Sigstore) |
| Deep link | A link that opens a station directly, such as `linefm://play?station=<station>` |
| Golden test | Image comparison of a UI against a stored reference image |
| laut.fm | The platform that carries the stations and supplies the app's data |
| Pre-release | A release with the suffix `alpha`, `beta` or `rc`; it goes to no store |
| Provider | Building block of state management (Riverpod) |
| SBOM | Software bill of materials: the parts a release is made of |
| Scorecard | OpenSSF check of a repository's security practices |
| TDDDG | German act on data protection in telecommunications and digital services; governs consent for access to end devices |
